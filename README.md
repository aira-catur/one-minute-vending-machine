# One-Minute Vending Machine

## The line

> My coil's been stuck all week, but you walked by — and suddenly everything in me wants to drop.

## How it runs

`main.py` (Python, standard library only, no network, deterministic) writes the line to `entry.txt` in the directory named by the `MAKEFUN_OUTPUT_DIR` environment variable, or `/output` when that is unset.
